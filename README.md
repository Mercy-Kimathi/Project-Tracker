# Linear Clone

A frontend-only Linear-inspired landing page and issue tracker built with Next.js, Tailwind CSS, Framer Motion, Zustand, and dnd-kit.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The marketing homepage is `/` and the interactive issue tracker is `/app`.

## Features

- Responsive marketing homepage with animated sections and pricing cards.
- Issue tracker with Kanban columns, drag-and-drop status updates, search, priority filtering, and issue creation.
- In-memory demo data; no backend or authentication.

## Deploy

Push the repository to GitHub, import it in Vercel, and deploy using the default Next.js settings.
