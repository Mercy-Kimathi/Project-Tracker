# Linear Clone

A polished, frontend-only Linear-inspired product landing page and issue tracker built with Next.js, Tailwind CSS, Framer Motion, Zustand, and dnd-kit.

## Run locally

```bash
npx create-next-app@latest linear-clone
cd linear-clone
# Copy this project into the generated folder, then:
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The marketing homepage is `/` and the interactive dashboard is `/app`.

## Features

- Dark, responsive marketing homepage with animated hero, feature grid, workflow section, and pricing cards.
- Dashboard with responsive sidebar, Kanban columns, drag-and-drop issue status updates, search, priority filter, and create-issue modal.
- Zustand in-memory state with seeded demo issues. No backend or authentication.

## Deploy to Vercel

1. Push the repository to GitHub.
2. Import it in [Vercel](https://vercel.com/new).
3. Keep the default Next.js build settings and deploy.
4. Add the live URL to this README.
